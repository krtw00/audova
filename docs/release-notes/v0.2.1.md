# Audova v0.2.1

macOS 向け無料音楽プレイヤー Audova のアップデートです (Apple Silicon / macOS 14+)。

## ✨ このリリースの主眼: 署名付き配布

**Developer ID 署名 + Apple notarize 済みの配布物になりました。** これまで必要だった Gatekeeper の回避手順 (`xattr -dr com.apple.quarantine` や「このまま開く」) は不要です。zip を展開して `Audova.app` を `/Applications` に移動し、そのまま起動できます。

## 新機能

- **出力デバイス選択** — transport bar の出力先メニューから再生デバイスを切り替えられるようになりました (AUD-19)

## v0.2.0 の主な機能 (再掲)

- ライブラリ管理: 再帰スキャン + 差分スキャン (未変更 skip / 削除検知)、メタデータ抽出、FTS 検索、3 ペイン表示、アルバムアート
- 再生: SFBAudioEngine ベース、再生キュー、シャッフル / リピート (off/all/one)、メディアキー / コントロールセンター連携
- プレイリスト: D&D で追加・並べ替え、M3U8 エクスポート (相対パス)

## 動作環境

- macOS 14 (Sonoma) 以降 / Apple Silicon
